# ぽじおレシピブック

インスタやレシピサイトで見つけた「また作りたい料理」を1か所にまとめる、個人用のレシピ帳です。
iPhoneのSafariで開いて「ホーム画面に追加」し、アプリのように使います。

- 一覧(料理の画像・★・作った回数)、検索、並べ替え
- URLや投稿の説明文を貼り付けると、材料と作り方に自動で分ける
- 自動取り込み(設定した場合): レシピサイトのURLを貼るとページを読み込み、スクショは文字を読み取って、そのまま登録する
- 買い物モード(材料のチェックリスト)、料理モード(手順を大きく表示し、画面のスリープを防ぐ)
- 作った記録、アレンジメモ、バックアップの書き出し・読み込み

レシピのデータは端末の中(IndexedDB)にだけ保存されます。
自動取り込みを使うときだけ、貼ったURLや選んだスクショを、利用者自身のGoogleアカウントに置いたApps Script(取り込み係)に送って読み取ります。スクショは読み取りに使った一時ファイルをすぐ削除します。取り込み係のプログラムと合言葉は、このリポジトリには含めていません。

## ファイル

- `src/app.html` … 本体
- `build.py` … `docs/`(GitHub Pagesで公開するPWA一式)を作る
- `test/run_parser.js` … 文章の振り分けの確認、`test/e2e.js` … ヘッドレスChromeでの操作確認
- `test/e2e_import.js` と `test/mock_relay.js` … にせの取り込み係を相手にした自動取り込みの確認

```
python3 build.py
```
